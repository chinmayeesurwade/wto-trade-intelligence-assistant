# 🌍 WTO Trade Intelligence Assistant

An AI-powered Retrieval-Augmented Generation (RAG) application that enables users to ask natural language questions about WTO accession, trade policy, membership, dispute settlement, and WTO agreements.

The application combines:

- WTO Knowledge Base
- ChromaDB Vector Database
- Sentence Transformers Embeddings
- Google Gemini LLM
- Streamlit Frontend

---

## 🚀 Features

### Semantic Search
Uses vector embeddings to retrieve relevant WTO documents based on meaning rather than keyword matching.

### Retrieval-Augmented Generation (RAG)
Retrieves WTO content from ChromaDB and provides contextual responses using Gemini.

### Source Attribution
Displays source URLs used to generate responses.

### WTO Knowledge Coverage

Supports questions related to:

- WTO Accession
- WTO Membership
- Trade for Peace Initiative
- WTO Agreements
- Trade Policy
- Dispute Settlement
- Technical Assistance
- Capacity Building
- WTO Commitments
- Working Party Reports

---

## 🏗 Architecture

User Question
↓
Sentence Transformer
(all-MiniLM-L6-v2)
↓
ChromaDB Vector Search
↓
Top Relevant WTO Chunks
↓
Gemini LLM
↓
Generated Answer + Sources

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/wto-rag-assistant.git

cd wto-rag-assistant
```

### Create Virtual Environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

## Sample Workflow

1. User enters question
2. Query embedding generated
3. ChromaDB retrieves top WTO documents
4. Context sent to Gemini
5. Gemini generates answer
6. Sources displayed
